# 강연 슬라이드 원고 (2026-10-27 개정)

「와이파이 탐정단 — 도서관의 숨은 전파를 찾아라!」 10월의 하늘 2026, 2026-10-31(토) 2부 15:00~15:50, 경기 김포시양곡도서관. 1부(14:00)는 최경묵 박사 「감정조절의 뇌과학」.

- 청중: 초등 4학년 이상 학생과 동반 학부모, 성인 신청 가능(정원 50명). 소규모 예상이라 **참가자 전원이 탐정**이 되는 운영을 기본으로 한다. 문구는 짧게, 숫자보다 막대와 색.
- 도입은 "우리나라는 무슨 강국일까요?" 질문으로 시작해 통신 강국이 된 네 장면(1885·1927 / 1984·1986 / 1996 / 2019)으로 이어진 뒤 와이파이 막대 사건을 제시한다. 영상은 틀지 않고 정지 화면과 한 줄 자막만 쓴다.
- 슬라이드와 강연 앱을 오간다. 앱 화면으로 넘어가는 지점은 `[앱 N]`으로 표시했다(발표 화면에서 숫자 키 N). 슬라이드는 도서관 공용 노트북, 앱은 강연자 노트북(측정 구간만 HDMI 교대).
- 아이들에게 "숙제" 대신 "탐정 미션"이라고 말한다.
- 용어는 정확하게: "재다" 대신 "측정하다", "세다" 대신 "강하다", "짐작" 대신 "추정". 말투는 해요체.
- 시간은 본 강연 40분 + 질의응답 8분 + 저장·인계 2분. 소규모면 질의응답을 늘린다.
