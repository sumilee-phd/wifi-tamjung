# 강연 슬라이드 원고 (초안)

「와이파이 탐정단 — 도서관의 숨은 전파를 찾아라!」 10월의 하늘 2026, 2026-10-31(토) 14:00~14:50, 대구 안심도서관 시청각실.

- 청중: 초등학생 중심(저학년 포함) 약 40명과 학부모. 문구는 짧게, 숫자보다 막대와 색.
- 슬라이드와 강연 앱을 오간다. 앱 화면으로 넘어가는 지점은 `[앱 N]`으로 표시했다(발표 화면에서 숫자 키 N).
- 아이들에게 "숙제" 대신 "탐정 미션"이라고 말한다.
- 용어는 정확하게: "재다" 대신 "측정하다", "세다" 대신 "강하다", "짐작" 대신 "추정". 말투는 해요체.
- 시간은 본 강연 40분 + 질의응답 8분 + 저장·인계 2분.
